# SkillSphere

SkillSphere is a full-stack community platform where developers and creators can showcase their projects, build professional profiles, discover other people's work, and interact through likes and comments.

## ✨ Features

- User signup and login
- JWT-based authentication
- Protected routes
- Developer / Creator roles
- Public user profiles
- Editable profile information
- Skills and social links
- Create projects
- Edit and delete projects
- Project image upload and preview
- GitHub and Live Demo links
- Explore projects
- Search projects
- Filter projects by technology
- Project details page
- Like / unlike projects
- Project comments
- My Projects workspace
- Project statistics
- Custom confirmation modal
- Toast notifications
- Responsive UI

## 🛠️ Tech Stack

### Frontend
- React
- React Router
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Multer
